# Tox 0.1.3 公开构建验证

Tox 从可选本地扩展迁入默认构建，源码、测试、透明图标和隔离测试截图一并发布。

## 构建与打包

- 执行不带 `--local` 的 `./tools/build.sh` 成功，`C1_BUILD_LOCAL_APPS=OFF`。
- 公共依赖清单固定 c-toxcore、cmp 子模块及 quirc；公共 Docker 工具链提供本机与 MIPS 的静态 libsodium。
- 生成 `c1max-tox`：ELF32 little-endian、MIPS32r2/o32；随包附带引导节点及依赖许可证。
- 默认包包含 20 个应用清单、Tox launcher 入口和 BGRA 透明图标。
- 用户身份、聊天记录、私有配置和旧集成备份不进入 Git 或设备包。

## 回归

在公共 `c1max-apps-builder:bookworm` 内构建 `tests/tox`，使用两个新建的测试身份，仅通过 `127.0.0.1` 通信：

- 人工接受好友请求、中英文双向收发及送达回执。
- 离线失败、输入长度限制、同一身份互斥锁。
- 重启后身份、昵称、好友与历史保留，目录 0700、文件 0600。
- 上一份有效快照可以恢复同一个身份与好友；损坏或全零主文件被保留，不自动创建新身份。
- Tox URI、校验码、自己的 ID 拒绝；真实二维码识别、四方向旋转、行填充、镜像和空帧。
- 1×／1.5×／2× 原始细节裁剪、对焦清晰度、搜索边界、无纹理回退和取消。

`tox-scan-test` 需要传入 `tox-qr <输出前缀>` 生成的 `.id` 文件，完整命令见 [应用 README](../tox/README.md#构建与验证)。
