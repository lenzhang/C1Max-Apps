# HID 键鼠

- Native LVGL at 800 × 340. Physical keyboard; no on-screen keyboard.
- Graphite canvas #101922, panels #1b2a36, text #eef5fa, muted #a7bac9, mint #5eead4.
- Noto Sans SC: 18 px controls, 16 px supporting text, 24 px title. Buttons at least 44 px tall.
- One screen: large touchpad on the left, mouse buttons / sticky modifiers / navigation keys on the right, wide USB connection status in the header.
- Return releases keys; power returns to launcher. USB is opt-in per session and restores original functions on exit.
- AI and voice belong to MoonPilot. This app never opens the camera or model settings.
